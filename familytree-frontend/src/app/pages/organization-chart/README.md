# 組織圖連接線修正說明

## 已完成的修正：

### 1. 圖層順序調整
- 將節點組件放在連接線組件之前渲染
- 設置連接線 z-index: 0，節點 z-index: 2
- 確保連接線在節點下方顯示

### 2. 連接點位置修正
- 連接線始終從節點的上下邊緣中心點連接
- 移除了終點偏移計算，讓線條直接連到卡片邊緣
- 箭頭通過 marker 的 refX 屬性自動保持正確位置

### 3. 連接線樣式優化
- 垂直連接使用直線
- 斜向連接使用平滑的貝茲曲線
- 同水平連接使用優雅的拱形曲線
- 減小了箭頭尺寸，使其更精緻

### 4. 節點尺寸校準
- 寬度：260px（固定）
- 高度：90px（包含 padding 和內容）

## 效果說明：
- 連接線現在完全在卡片下方
- 兩端都正確連接到卡片邊緣
- 箭頭指向卡片但不會重疊
- 曲線更加平滑自然
