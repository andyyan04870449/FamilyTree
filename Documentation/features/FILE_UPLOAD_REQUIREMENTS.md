# 檔案上傳功能需求文件，這個工能要有測邊功能欄捷徑

1、用戶只能上傳xls、xlsx

2、上傳之後，會記錄在檔案上傳頁面的下半部進行記錄，並顯示該檔案當前的狀態(根據後面開發提供的資訊，提供適合揭露的資訊)

3、上傳之後，將檔案用MD5確認是否曾經上傳過，如果沒有上傳過，就保存在本地的user_update目錄

4、如果上傳成功，就在資料庫中的user_update_file表格中，保存上傳時間、MD5、檔案在本地的資訊(方便未來存取)、沒有將資料拷貝入庫的欄位名稱(用逗點分隔)

5、創建一個全新的表格來將用戶上傳的檔案copy入這個表格，這個表格的欄位要有以下：
檔案MD5(唯一PK),照片, 姓名, 發掘經過, 性別, 生日, 出生地（父母戶籍所在地）, 國籍, 民族, 籍貫（祖父戶籍所在地）, 黨派, 身分證號碼, 護照號碼, 電話, 行動電話, 電子信箱, 現職單位, 現居地址, 通訊地址, 親屬關係（職稱，姓名）, 經歷（單位，職稱，任職期間）, 學歷, 網路帳號, 著作（名稱，共同作者）, 參與活動（活動名稱，參與人士）, 重要友人（姓名，單位，關聯事件）, 經常出入場所, 出國紀錄, 備註, 建檔時間, 建檔人, 最後更新時間, 最後更新人

6、創建一個表格來mapping用戶上傳的資料欄位要對應到上述那張個的哪一個欄位
這個表格一欄是excel表格上的欄位名稱，一欄是資料庫中欄位的名稱，
一個資料庫欄位的名稱可以擁有多個excel欄位名稱，供用戶提供不同種規格的excel檔案
但唯一不變的道理就是，從excel表的欄位名，到這個表格中查找應該要存到到哪一個資料庫欄位
如果找不到，就捨棄這筆資料，並且要在user_update_file中紀錄有哪幾個欄位沒有入庫

7、當用戶上傳檔案成功之後，應該進行資料拷貝入庫的工作，拷貝邏輯是：
根據excel欄位上方的名稱，到mapping表格中查找應該將該筆資料放在哪一個欄位，如果找不到就將欄位名稱保存下來，供後續儲存結果用;將所有可以保存的資料搜集起來後，寫入資料庫保存。
萬一excel有兩個欄位被指向同一個資料庫欄位，則將該內容加入一個換行符號後將資料追加在後面。

8、完成上傳之後，應該要在“人員管理”的“人員列表”介面中，顯示所有資料庫中的人員資料，為了加快速度，每一個頁僅提供20個人，並且提供換頁與跳頁功能給用戶選。

9、用戶可以在“人員管理”的“新增人員”中自主新增一個人員，這個表單介面要有資料庫中所有對照的欄位，除了人名不可空白之外，其他皆可。
