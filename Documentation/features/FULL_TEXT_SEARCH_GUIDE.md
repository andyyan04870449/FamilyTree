# 全文檢索功能說明文件
## 🎯 功能概述

### 主要功能
- **關鍵字搜索**：支援精準查詢和模糊查詢
- **歷史記錄**：自動保存查詢歷史
- **熱門關鍵字**：顯示常用搜索詞
- **收藏管理**：個人化收藏功能
- **結果篩選**：多條件組合查詢

### 支援的查詢類型
- [ ] 姓名查詢
- [ ] 關鍵字查詢
- [ ] 時間範圍查詢
- [ ] 組合條件查詢

## 🔍 查詢功能

### 1. 基本查詢

#### 精準查詢
- **功能說明**：使用資料庫的精準比對去查詢
- **使用時機**：當用戶界面上選擇精準查詢的flag時候使用
- **操作步驟**：
  搜尋的時候，進入資料庫找尋所有與關鍵字有關的文字，只要有精準比對到，就挑選出來

#### 模糊查詢
- **功能說明**：使用資料庫的模糊比對去查詢
- **使用時機**：當用戶界面上選擇模糊查詢的flag時候使用
- **操作步驟**：
搜尋的時候，進入資料庫找尋所有與關鍵字有關的文字，只要有模糊比對到，就挑選出來

### 3. 歷史記錄
- **自動保存**：每一次搜尋輸入的關鍵字就記錄到搜尋關鍵字紀錄表來，並且將其次數+1
- **清除記錄**：系統設定中提供按鈕去清理
- **快速重用**：無

### 4. 熱門關鍵字
- **更新頻率**：每次進入頁面的時候更新
- **計算方式**：每一次搜尋輸入的關鍵字就記錄到搜尋關鍵字紀錄表來，並且將其次數+1
- **顯示數量**：根據搜尋關鍵紀錄表上的次數總計

## ⭐ 收藏功能

### 1. 添加收藏
- **操作方式**：用戶搜尋出來的資料會提供一個收藏功能，點擊收藏會將其資料保存起來
- **收藏限制**：沒有數量限制
- **重複處理**：如果資料庫表示已經有收藏了，則提示前端用戶即可，如果查出來的資料是已經收藏的，需要顯示已收藏

### 2. 管理收藏
- **查看收藏**：每當進入全文檢索的時候，會出現在右側
- **編輯收藏**：每一個收藏的人名右邊有個垃圾桶符號，代表按下去會刪除收藏
- **刪除收藏**：每一個收藏的人名右邊有個垃圾桶符號，代表按下去會刪除收藏

### 3. 收藏排序
- **排序方式**：
  - [ ] 按最後查看資料的時間，如果沒有查看的時間，就按照最後增加的時間

## 📋 操作說明

### 1. 基本操作流程

#### 開始搜索
1.輸入關鍵字
2、選擇模糊或是精準，預設是模糊
3、點擊查詢

#### 查看結果
1. 可以在搜尋的下方檢視結果，每一筆結果有一個check box，用來提供其他功能使用
2.每一筆資料的最右側都有功能匡，目前規劃有檢視(彈出人員的基本資料，與人員列表中已開發的功能相同)、收藏

#### 管理收藏
1. 無
